# CEOS v10.2 — Conversación natural + Grafo Vivo de obras y proyectos

## Cambios principales
- Conversación orgánica por defecto: las banalidades no disparan investigación web ni análisis CRONOS pesado.
- La casilla de Internet deja de ser engañosa: por defecto está apagada; las peticiones explícitas de investigar/buscar pueden activar web.
- Continuidad conversacional persistente dentro de cada sesión.
- Las conversaciones casuales no contaminan el grafo con nodos por palabra; se registra continuidad de forma compacta.
- Grafo vivo ampliado con literatura + invención.
- Nuevos proyectos sembrados: FORMA 333 / Olla lenta, SAD / Tubería y CRONOS-333.
- Perfiles de obra/proyecto y pantalla «Mis obras y proyectos».
- Descripciones y procedencia epistemológica de los inventos conservadas en el grafo.
- Las cifras técnicas de los inventos se mantienen como datos de fuente del proyecto y pendientes de validación cuando así corresponde; CEOS no las presenta como hechos independientes.

## Corpus de los inventos incorporado
La semilla procede del archivo aportado por el usuario `Olla lenta y Tubería comprimido_28-09-2026.zip`, que contiene la presentación de FORMA 333 y el paquete documental de SAD. Se incorporaron resúmenes estructurados, no se sustituyeron los documentos originales.

## Conversación
CEOS distingue entre charla cotidiana, conversación de continuidad y tareas de estudio. En charla cotidiana puede simplemente conversar, responder a un saludo, un comentario o un agradecimiento sin convertirlo en una lección.
