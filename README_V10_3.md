# CEOS 10.3.0 — Charla cotidiana + Portugués europeo profesional

Esta versión conserva el grafo vivo y la conversación continua de 10.2 y añade una ruta específica de idiomas centrada en **portugués europeo (Portugal)**.

## Nuevo

- Portugués configurado como **pt-PT** en dictado del navegador.
- Correcciones específicas para interferencias de un hispanohablante.
- Distinción entre portugués europeo y brasileño cuando afecta al objetivo laboral.
- Nueva charla cotidiana `pt-daily` para priorizar fluidez antes que teoría.
- Ruta profesional basada en la oferta aportada para **Técnico Productividad y Procesos CASH** de Prosegur:
  - entrevista;
  - UAT y validación operativa;
  - mejora de procesos;
  - manuales, implementación y soporte;
  - viajes España–Portugal.
- Endpoint `GET /api/lang/program?target_lang=pt`.
- Panel web de ruta profesional y foco lingüístico.
- Vocabulario operativo: formação, gestão, melhoria contínua, aplicação, utilizador, equipa, ficheiro, ecrã, implementação, suporte, deslocações.

## Criterio de aprendizaje

La charla cotidiana no debe convertirse automáticamente en una clase. CEOS conversa primero, corrige pocos elementos de alto valor y después recicla la forma correcta en nuevos turnos.

La ruta profesional aumenta gradualmente la dificultad: conversación → entrevista → UAT/procesos → implantación/soporte.
