CEOS v8.1.0 — corrección LLM / Groq (24-09-2026)
===========================================================

La v8.0 usaba por defecto IDs Groq antiguos. En v8.1 CEOS abandona esa dependencia:
prueba modelos actuales y hace fallback automático cuando uno está retirado o bloqueado.

MODELOS ACTUALES DE REFERENCIA
-------------------------------
openai/gpt-oss-120b
openai/gpt-oss-20b
qwen/qwen3.8-27b
minimaxai/minimax-m2.7

Si CEOS_GROQ_MODEL contiene un ID retirado conocido, se ignora automáticamente.

DESPLIEGUE EN RENDER
--------------------
1. Sube/reemplaza TODO el proyecto en GitHub.
2. Render hará el redeploy.
3. No hace falta borrar CEOS_GROQ_MODEL si tenía un modelo antiguo: v8.1 lo salta.
4. Mantén GROQ_API_KEY como secreto de Render.

Comprobación sin generar texto:
https://ceos-ceox-3.onrender.com/api/llm/status?probe=1

O desde CEOS → Inicio → Motor de redacción → Comprobar API.

Interpretación:
- probe.ok=true: credencial aceptada y se ven modelos.
- 401: credencial inválida/caducada.
- 403: permisos/modelo/proyecto.
- 429: cuota o rate limit.

El chat ya no presenta cualquier 403 como “clave mala”. Además, si un modelo no
funciona, intenta automáticamente el siguiente modelo actual disponible.
