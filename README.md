# CEOS v10.3

CEOS es un agente persistente construido alrededor de un LLM, con memoria, conversación, aprendizaje por feedback, agencia acotada, laboratorio de autor, Mente Fractal y, desde v10, un **Grafo Vivo de Coevolución**.

El grafo relaciona el usuario, sus obras/proyectos y el conocimiento de CEOS. Su objetivo no es simular conciencia sino conseguir continuidad funcional: recordar qué interesa, detectar qué falta por comprender, decidir cuándo enseñar, cuándo investigar y cuándo abrir una prueba de transferencia.

## Inicio local

Ejecuta `INICIAR_CEOS.bat`.

## Despliegue online

El paquete conserva Docker, Gunicorn y `render.yaml`. En Render guarda API keys y `CEOS_MIND_KEY` como secretos. Para la memoria persistente utiliza una ruta de almacenamiento persistente.

## Regla de conocimiento

E1/E2/E3 son niveles de evidencia documental/contextual; E4 y E5 son hipótesis/especulación de trabajo. CEOS debe evitar elevar E4/E5 a hecho sin nueva evidencia.
