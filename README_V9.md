# CEOS v9.0 — Fractal Mind

Esta versión evoluciona CEOS desde **Living Entity + Adaptive Mentor + Author Lab** hacia una arquitectura de **Maestro profundo + Aprendiz permanente**.

## Conocimiento semilla incluido

Autor y corpus del usuario; CRONOS-Espiral-OCa; astroteología/astronomía cultural; gnosis; Béchamp; Caramuel; Isaac Peral; Miguel Servet; Nietzsche; Lakhovsky; Cervantes; Lope de Vega; Giordano Bruno; teoría de números; astrología.

## Uso

Local: ejecutar `INICIAR_CEOS.bat`.

Online: desplegar el contenido en el repositorio conectado a Render y mantener `CEOS_MIND_KEY` como secreto persistente.

## Endpoints nuevos

- `GET /api/mind/status`
- `GET /api/mind/search?q=...`
- `POST /api/mind/learn`
- `POST /api/mind/consolidate`
- `GET /api/mind/teacher`
- `GET /api/mind/questions`
- `POST /api/mind/seal`

## Principio

CEOS debe aprender sin borrar sus dudas: conservar fuentes, niveles de evidencia, conflictos y preguntas abiertas.
